# 澄听 · CET-6 伴学

面向 CET-6 的渐显听力、作文评估和资料管理网页。可直接部署到 GitHub Pages，在手机或电脑浏览器使用。

## 已实现

- 三遍渐显听力：盲听、半遮、全文核对
- 浏览器本机英文语音，无 API Key 也可播放
- 听写准确率、漏词和多写词分析
- 手动导入真题/自有听力原文并生成练习
- Bilibili 练习入口（仅跳转，不抓取内容）
- DeepSeek、MiMo 和自定义 OpenAI 兼容接口
- 无 Key 作文字数、结构、衔接和词汇预评估
- 有 Key 时的结构化作文评分与逐句修改
- 本地资料库与学习记录
- PWA、响应式手机界面和当前链接二维码
- GitHub Pages 自动部署流程

## 本地运行

```bash
npm install
npm run dev
```

构建与测试：

```bash
npm test
npm run build
```

## 发布到 GitHub Pages

1. 新建 GitHub 仓库并将本目录推送到 `main` 分支。
2. 在仓库 `Settings → Pages` 中，将 Source 选择为 `GitHub Actions`。
3. 等待 `Deploy to GitHub Pages` 工作流完成。
4. 打开 Pages 链接；首页“手机打开”会显示该链接的二维码。

## API Key 安全

这是静态网页，无法像服务器那样隐藏密钥。设置页默认不永久保存 Key，并支持填写自己的云函数代理地址。正式公开使用时，推荐通过只允许指定域名访问的代理转发请求，同时设置额度限制。

无 Key 时仍可使用听力播放、渐显字幕、听写对比、资料导入和作文基础预评估。

## 内容说明

仓库只内置原创功能示例，不收录来源或授权不明确的真题。用户可在“真题资料”中导入自己拥有或获准使用的原文。AI 原创材料与真题应始终分开标识。
